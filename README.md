# ilyakolesnik.com

Персональный сайт Ильи Колесникова.

## Структура

- `index.html` — главная страница с видео-фоном, именем, слоганом, входами в разделы и выпадающим списком ссылок.
- `art/` — будущий раздел с арт-проектами.
- `motion/` — будущий раздел с motion-проектами.
- `assets/` — медиа для сайта, включая `background.mp4` и `hero-poster.jpg`.
- `styles.css` — общие стили сайта.
- `script.js` — небольшое поведение интерфейса, включая показ видео после загрузки.
- `CNAME` — кастомный домен для GitHub Pages.

## Локальный просмотр

Открой `index.html` в браузере или запусти простой локальный сервер из этой папки:

```bash
python3 -m http.server 8000
```

## Деплой

Проект готов для GitHub Pages в режиме `Deploy from a branch`:

- branch: `main`
- folder: `/ (root)`
