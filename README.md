# ilyakolesnik.com

Персональный сайт Ильи Колесникова.

## Структура

- `index.html` — главная страница с видео-фоном, именем, слоганом, входами в разделы и выпадающим списком ссылок.
- `data/projects.js` — структурированный список проектов, секций, тегов, описаний и медиа.
- `projects/<slug>/index.html` — отдельные маршруты проектов.
- `project-page.js` и `project-page.css` — временная общая вёрстка внутренних страниц проектов.
- `assets/backgrounds/` — короткие видеофоны главной страницы, которые проигрываются в случайном порядке.
- `assets/projects/` — папки проектов; сюда кладём обложки и медиа для карточек/внутренних страниц.
- `styles.css` — общие стили сайта.
- `script.js` — поведение главной страницы: фильтры, карточки, бегущая строка и видеофоны.
- `CNAME` — кастомный домен для GitHub Pages.

## Локальный просмотр

Открой `index.html` в браузере или запусти простой локальный сервер из этой папки:

```bash
python3 -m http.server 8000
```

## Деплой

Проект готов для GitHub Pages в режиме `Deploy from a branch`:

- branch: `main`
- folder: `/ (root)`
